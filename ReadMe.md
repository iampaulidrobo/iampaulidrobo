## 🛠️ ROS developer tools I'm building

| Project | What it does |
|---|---|
| [**ROS Darshan**](https://github.com/iampaulidrobo/ros_darshan) | Live observability for ROS 2: auto-discovered node/topic graph, particle-flow edges showing real message rates, Hz/bandwidth stats and rule-based diagnostics. |
| [**ROS Node Designer**](https://github.com/iampaulidrobo/ros_node_designer) | VS Code extension: design a ROS 2 pub/sub node graph visually and generate a compile-ready `ament_cmake` package. |
| [**Rosbag Analyzer**](https://github.com/iampaulidrobo/rosbag_analyzer) | VS Code extension: open `.bag` files, plot topics and generate SLAM trajectory-accuracy (evo) reports, no ROS install needed. |
| [**URDF Studio**](https://github.com/iampaulidrobo/urdf-studio) | VS Code extension: edit, visualise and navigate URDF robot descriptions. |
